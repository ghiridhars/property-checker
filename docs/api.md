# REST API Reference

The web UI is backed by a FastAPI application (`api/main.py`). The server runs on `http://localhost:8000` by default. All endpoints are under the `/api` prefix.

Interactive docs (auto-generated by FastAPI) are available at:
- Swagger UI: `http://localhost:8000/docs`
- ReDoc: `http://localhost:8000/redoc`

No authentication is required. This is a personal local tool.

---

## Config

### `GET /api/config`
Returns the current search configuration. Reads from MongoDB `scraper_config` collection; falls back to `config.py` defaults if no document exists.

**Response `200`**
```json
{
  "locations": ["Trivandrum", "Manacaud"],
  "property_types": ["2 bhk", "2bhk"],
  "must_keywords": ["vastu", "east facing"],
  "reject_keywords": ["pg", "hostel"],
  "max_price_inr": 6000000
}
```

---

### `PUT /api/config`
Saves the search configuration to MongoDB. The updated config is picked up on the next scraper run.

**Request body** — same shape as the GET response.
```json
{
  "locations": ["Trivandrum", "Manacaud", "Pettah"],
  "property_types": ["2 bhk", "2bhk"],
  "must_keywords": ["vastu", "east facing", "ground floor"],
  "reject_keywords": ["pg", "hostel", "commercial"],
  "max_price_inr": 5500000
}
```

**Response `200`**
```json
{ "ok": true }
```

## Scrapers

### `GET /api/scrapers`
Returns all registered scrapers and their current enabled state.

**Response `200`**
```json
[
  { "name": "olx",          "enabled": true,  "status": "active" },
  { "name": "magicbricks",  "enabled": false, "status": "js_only" },
  { "name": "99acres",      "enabled": false, "status": "blocked" }
]
```

`status` values:
| Value | Meaning |
|---|---|
| `active` | Works with plain HTTP requests |
| `js_only` | Page is React/Vue — needs Playwright to scrape |
| `blocked` | Returns 403 — WAF / anti-bot protection active |

---

### `PUT /api/scrapers/{name}`
Enable or disable a specific scraper. Persisted in `scraper_config`.

**Path param** — `name`: scraper identifier (e.g. `olx`, `magicbricks`, `99acres`)

**Request body**
```json
{ "enabled": true }
```

**Response `200`**
```json
{ "ok": true, "name": "olx", "enabled": true }
```

**Response `404`** — scraper name not found
```json
{ "detail": "Scraper 'unknown' not found." }
```

## Run

### `POST /api/run`
Triggers an immediate scraper run in a background task. Returns immediately; poll `/api/run/status` to track progress.

**Response `202`**
```json
{ "started": true }
```

**Response `409`** — a run is already in progress
```json
{ "detail": "A scraper run is already in progress." }
```

---

### `GET /api/run/status`
Returns the state of the most recent run.

**Response `200`**
```json
{
  "running": false,
  "last_run_at": "2026-05-13T10:22:49Z",
  "last_run_new_count": 3,
  "last_run_error": null
}
```

| Field | Type | Description |
|---|---|---|
| `running` | bool | `true` while a background run is active |
| `last_run_at` | ISO 8601 string \| null | Timestamp of last completed run |
| `last_run_new_count` | int | New listings found in the last run |
| `last_run_error` | string \| null | Error message if the last run failed |

## Listings

### `GET /api/listings`
Paginated list of all saved listings, sorted by `discovered_at` descending.

**Query parameters**

| Parameter | Type | Default | Description |
|---|---|---|---|
| `page` | int | `1` | Page number (1-based) |
| `limit` | int | `20` | Results per page (max 100) |
| `source` | string | — | Filter by portal (e.g. `olx`) |

**Response `200`**
```json
{
  "total": 47,
  "page": 1,
  "limit": 20,
  "items": [
    {
      "property_id": "olx-1234567890",
      "title": "2 BHK Apartment Manacaud",
      "price": "45 Lac",
      "price_inr": 4500000,
      "source": "olx",
      "url": "https://www.olx.in/item/...",
      "discovered_at": "2026-05-13T10:22:49Z"
    }
  ]
}
```
